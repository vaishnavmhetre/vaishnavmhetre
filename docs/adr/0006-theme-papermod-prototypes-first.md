# Theme: PaperMod baseline with deliberate customization, prototypes first

Start from the **PaperMod** Hugo theme for solid, fast defaults, then customize typography, the case-study layout, and project cards so the result does not read as stock.

Because the visual direction is a genuine fork — **animation-forward/techy** vs **polished professional minimalism** — both directions will be **prototyped and reviewed before theme work is committed**. Design sense comes from the `frontend`/`animate`/`hallmark`/`impeccable` skill set; the prototypes are throwaway and reviewed side-by-side. Trade-off this records: a stock theme ships faster but signals nothing; a bespoke look ships slower but is the differentiator for an engineer-led audience.
